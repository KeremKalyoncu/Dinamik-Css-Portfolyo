## 📋 Hakkında

Framework kullanmadan, saf CSS3 ve JavaScript ile oluşturulmuş interaktif portfolyo
denemesi. Dinamik stil değişimleri ve kullanıcı etkileşimlerine tepki veren arayüz
öğeleri içerir.

## ✨ Özellikler

- 🎨 Dinamik CSS geçişleri ve animasyonlar
- ⚡ Framework'süz, saf (vanilla) JavaScript
- 📱 Duyarlı tasarım
- 🖱️ Etkileşimli arayüz öğeleri

## 🚀 Çalıştırma

```bash
git clone https://github.com/KeremKalyoncu/Dinamik-Css-Portfolyo.git
```

`index.html` dosyasını tarayıcıda açmanız yeterlidir; derleme adımı yoktur.

## 📁 Yapı

```
Dinamik-Css-Portfolyo/
├── index.html      # Ana sayfa
├── style.css       # Dinamik stiller
└── main.js         # Etkileşim mantığı
```
